## Cross-page definitions

A finalize check fails when its definition is true. Evidence is what the finding must name.

### `sitemap.non_indexable_url` — A sitemap lists a URL that is not indexable

Fails for each URL listed in any of the audit’s sitemaps whose page was fetched but is not indexable: the final status is not 200, the final response is not HTML, the page has noindex in meta robots or in an applicable X-Robots-Tag header, or its canonical points at a different URL. Exclude URLs that robots.txt disallowed (page.blocked_by_robots covers those). Evidence: the URL, the sitemap that lists it and the reason it is not indexable (status, directive or canonical target).

### `page.blocked_by_robots` — An internal URL is blocked by robots.txt

Fails for each URL that the crawl discovered as an internal link or as a sitemap URL but robots.txt disallows for the crawler’s user agent, so the URL was never fetched (status 0 and robots_allowed false). Evidence: the blocked URL and one source page (or the sitemap URL) that references it; one evidence item per blocked URL, with the first source.

### `crawl.deep_page` — An indexable page is more than four clicks from the home page

Requires a complete link graph. Graph checks are suppressed when coverage is truncated.

On an audit whose coverage graph is complete (no page, depth or time limit truncated it), fails for each indexable 200 HTML page whose click depth from the seed through internal links is greater than 4. Pages with no depth (sitemap-only or listed URLs) are not reported. Evidence: the URL and its depth.

### `crawl.orphan_page` — A sitemap page has no internal links

Requires a complete link graph. Graph checks are suppressed when coverage is truncated.

On an audit whose coverage graph is complete, fails for each indexable 200 HTML page that is listed in a sitemap but has zero internal inlinks from other crawled pages. Evidence: the page URL and the sitemap that lists it.

### `indexability.noindex_in_sitemap` — A sitemap lists a URL that is noindex

Fails for each URL listed in a sitemap that was fetched as a 200 HTML page whose meta robots or applicable X-Robots-Tag contains noindex (or none). Evidence: the URL, the directive and whether it came from the meta tag or the header, and the sitemap that lists it.

### `canonical.to_non_200` — The canonical points at a URL that is not 200

Fails for each crawled 200 HTML page whose declared canonical points at another URL on the same site that was fetched and did not return 200 (4xx, 5xx, or a fetch failure with status 0). Evidence: the page URL, its canonical target, and the target’s status or fetch error.

### `canonical.to_redirect` — The canonical points at a redirecting URL

Fails for each crawled 200 HTML page whose declared canonical points at another URL that returns a 3xx redirect rather than a 200 response. Evidence: the page URL, the canonical target and the redirect status.

### `canonical.to_noindex` — The canonical points at a noindex page

Fails for each crawled 200 HTML page whose declared canonical points at another crawled URL that is noindex through meta robots or an applicable X-Robots-Tag header. Evidence: the page URL, the canonical target and the directive that makes the target noindex.

### `canonical.chain_or_cycle` — Canonicals form a chain or a cycle

Fails for each crawled 200 HTML page whose declared canonical points at another crawled page that declares a different canonical, forming a chain of two or more canonical hops, or whose chain returns to a URL already in it, forming a cycle. Follow only same-site targets. Evidence: the ordered chain of URLs from the page to the URL with no further canonical, or to the first repeated URL in a cycle.

### `links.broken_internal` — An internal link points at a broken URL

Fails for each internal link edge whose target URL was fetched and returned a 4xx or 5xx status, or failed to fetch (timeout, DNS, TLS). Robots-blocked targets are excluded (page.blocked_by_robots covers them). Evidence: the target URL, its status or failure, the source page that links to it and the anchor text; one evidence item per source page, capped at 50 source pages per target.

### `links.to_redirect` — An internal link points at a redirect

Fails for each internal link edge whose target URL answers with a 3xx redirect instead of a 200 response. Evidence: the target URL, the redirect status, the source page and the anchor text; one evidence item per source page.

### `title.duplicate` — Several pages share a title

Fails for each group of two or more indexable 200 HTML pages in the audit whose title text is identical after trimming and collapsing whitespace (case-sensitive). Pages with no title or an empty title are excluded (title.missing and title.empty cover them). Evidence: one item per URL in the group, each carrying the shared title, capped at 50 URLs per group.

### `description.duplicate` — Several pages share a meta description

Fails for each group of two or more indexable 200 HTML pages in the audit whose meta description is identical after trimming and collapsing whitespace (case-sensitive). Pages with no meta description are excluded (description.missing covers them). Evidence: one item per URL in the group, each carrying the shared description, capped at 50 URLs per group.

### `content.duplicate` — Several pages have identical content

Fails for each group of two or more indexable 200 HTML pages in the audit whose main-content hash (sha256 of the normalised visible text) is identical and is not the hash of an empty body. Evidence: one item per URL in the group, each carrying the shared hash and the page’s word count, capped at 50 URLs per group.

### `hreflang.missing_return` — An hreflang target does not link back

Fails for each hreflang entry on page A whose target URL B was crawled and is indexable, where B has no hreflang entry that points back to A (matching A’s language code, or an x-default entry pointing at A). Evidence: A, B and the language code whose return link is missing.

### `hreflang.to_non_canonical` — An hreflang target is not its own canonical

Fails for each hreflang entry whose target URL was crawled and is not its own canonical: the target is not indexable (noindex in meta robots or X-Robots-Tag, or a non-2xx status), or the target declares a different canonical. Evidence: the source page, the hreflang code and the target URL with the reason.
