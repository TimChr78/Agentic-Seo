- The new `fetch` package is the only path that reaches arbitrary URLs: DNS-pinned connections checked against private, loopback, link-local and metadata ranges (IPv4, IPv6 and their embedded forms), manual redirects re-validated per hop, ports locked to 80/443 unless a site allows more, and an explicit per-site allow-list for homelab and staging hosts.
- Responses are streamed with a decoded-byte cap (10 MB HTML, 2 MB other): oversized HTML comes back truncated so an audit can still read the head, and a gzip bomb is stopped on decoded size. Decode errors, stalls and socket resets propagate through `stream.pipeline` and always settle within the request deadline, every `Content-Encoding` in the list is undone in reverse order (with a cap at each stage), and an encoding the fetcher cannot decode fails with `unsupported_encoding` instead of returning raw bytes as text.
- The request authority always comes from the URL: a caller-supplied `Host` or `:authority` header is refused (`blocked_header`) and the TLS server name is the URL's host, so a certificate for another name can never be accepted. Credentials are scoped to exact origins (scheme + host + port) and are dropped on any origin change, including an https → http downgrade or a different port.
- The address guard also refuses the Teredo (`2001::/32`) and local-use NAT64 (`64:ff9b:1::/48`) transition ranges outright, in addition to the embedded-IPv4 checks for NAT64 and 6to4.
- robots.txt is fetched through the same guard, parsed with Google precedence and cached per origin (4xx allows, 5xx and unreachable disallow temporarily); an oversized file is read as a bounded prefix cut at the last complete line rather than becoming "disallow everything". An in-memory per-host limiter enforces concurrency, crawl-delay and `Retry-After`; it remembers the next start time after the last lease is released, so sequential requests still respect crawl-delay.
- The package also defines the renderer port, with a `none` renderer that reports "Not evaluated" rather than an empty page.
