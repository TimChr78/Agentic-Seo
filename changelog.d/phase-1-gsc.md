- Add the `integrations` package: per-site connections with sealed OAuth tokens, Google Search Console as the first connector, and an open connector registry for the GitHub connector that arrives with change sets.
- Add Google OAuth 2.0 with PKCE for Search Console: one OAuth client per installation (`GOOGLE_OAUTH_CLIENT_ID` and `GOOGLE_OAUTH_CLIENT_SECRET`), the `webmasters.readonly` scope only, a hashed one-time state, and `/oauth/callback` at `PUBLIC_URL`. Tokens are refreshed a few minutes before expiry under a lease; a refused refresh marks the connection `error` with “Google refused the refresh token; reconnect Search Console”.
- Add the Search Console provider adapter for `sites` and `searchAnalytics`, with `dataState: all`, `byProperty` and `byPage` aggregation, pagination and a conservative rate-limit bucket. Search Console is free, so its calls settle at zero.
- Add migration `0008_connections_gsc.sql`: `connections` and the `gsc_property_totals`, `gsc_page_aggregates` and `gsc_sync_state` tables, with row-level security and app-role grants. Search facts are plain tables indexed by `(workspace_id, site_id, date)`; monthly partitioning is deferred because RLS is not enforced per partition.
- Add `search.gsc.connect`, `properties`, `select`, `disconnect`, `status` and `sync`: connecting, choosing a property and disconnecting are people-only `settings` changes; listing properties and syncing are free reads.
- Add the Search Console sync: a 16-month first backfill in 30-day chunks that resumes from its watermark, a daily refresh of the last four provisional days, and `is_final` flipped once Google stops revising a day. Data older than about three days is final.
- Add `search.performance` (daily property totals with period totals and `provisionalFrom`) and `search.pages` (top pages by clicks with a cursor).
- Add `estimateReach`: known only with an active Search Console connection and page aggregates newer than four days, with 28-day clicks and impressions at risk, the same window a year earlier and the home page as the critical page. Unknown reach names what is missing.
- Show Search Console as connected in `sites.checklist` only when an active connection has a selected property.
- Add the worker tasks `connections_refresh` (every five minutes) and `gsc_sync` (daily per connection, or on demand), and an `aseo doctor` check that names the missing Google setting and links the setup guide.
